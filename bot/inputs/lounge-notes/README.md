# lounge-notes

実際に訪れたラウンジのメモ、または事前にリサーチした一次情報メモを `YYYY-MM-DD.md` の形式でこのディレクトリに置くと、
`generate-article.ts` がその日の記事生成時に最優先の事実source of truthとして読み込みます。

該当日のファイルが無い場合は、このディレクトリにある未使用のメモを1件先着順で使用します。
メモも無い場合は、一般的な傾向として書ける内容にフォールバックします。

このディレクトリの中身(`README.md`を除く)はgit管理対象外にすることを推奨します
(実体験メモは公開前の下書き素材であり、リポジトリに残す必要はないため)。
